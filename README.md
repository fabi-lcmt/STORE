Descripción del Proyecto: E-commerce de Ropa para Hombres: Gentlemen's Wardrobe
Este proyecto es una tienda en línea dedicada a la venta de ropa para hombres, desarrollada utilizando tecnologías web básicas como html, css y JavaScript. El sitio web ofrece una experiencia de compra intuitiva y atractiva, con un diseño moderno y responsive que se adapta a diferentes dispositivos como una laptop, celulares, tablets, etc.

Características Principales:

  1. Diseño Responsive:
        ◦ El sitio está diseñado para ser completamente responsive, asegurando una experiencia óptima en cualquier dispositivo.
        ![imagen](https://github.com/user-attachments/assets/09c72e48-e014-4d7d-8bcf-90d34559abad)
        ![imagen](https://github.com/user-attachments/assets/762db902-092d-46c9-a69e-eaf489e445df)

  2. Catálogo de Productos:
        ◦ Muestra una variedad de productos organizados en categorías que son abrigos, camisetas, pantalones, calzados y chamarras.
        ◦ Cada producto tiene una página detallada con imágenes y precio.
  3. Carrito de Compras:
        ◦ Implementación de un carrito de compras dinámico usando JavaScript.
        ◦ Los usuarios pueden agregar, eliminar y actualizar la cantidad de productos en el carrito.
        ◦ Cálculo automático del total de la compra.
        ![imagen](https://github.com/user-attachments/assets/bdbcd538-0071-46ce-ab1b-51a18f84fded)
  4. Diseño Atractivo:
        ◦ Uso de animaciones y transiciones en CSS para mejorar la interactividad.
        ◦ Paleta de colores moderna y tipografía legible.
  5. Interacción del Usuario:
        ◦ Notificaciones dinámicas por ejemplo, cuando se agrega un producto al carrito.
  6. Gestión de stock estático:
        ◦ Cuando un producto se agota, se muestra un mensaje de "No hay suficiente stock disponible" y se desactiva la opción de añadirlo al carrito.
        ![imagen](https://github.com/user-attachments/assets/0059f6de-f460-45af-be4a-dc794067fc90)

Tecnologías Utilizadas:

  • HTML5: Estructura semántica del sitio.
  
  • CSS: Estilos, animaciones y diseño responsive.
  
  • JavaScript: Funcionalidades dinámicas como el carrito de compras, filtros y validaciones.
